Vendors deliver the AI. Somebody has to measure what it actually delivered.

  • Point the agent at a running web app: it crawls, records what is broken, and provisions a Playwright + Playwright MCP project in one run.
  • That run is the surface probe of a seven-phase engagement: baseline, golden set, eval cube, cost ledger, pilot, verdict. The process page lays it out.

What "agent" means here

Scoped automation, not a chat assistant.

  • One folder, one CLI, a few REST routes, one node:test suite.
  • Every deliverable exists with LLM_PROVIDER=none: crawl, findings, generated project, report.
  • Findings and artifacts land in SQLite, so every number in a report traces to a run id.
  • The adapter only talks to a model you run yourself; public endpoints are rejected.
"One job, one contract — composable, scriptable, and boring by design."
